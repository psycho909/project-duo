# RWD 臨時規範（摺疊機過渡期）

公司正在研擬摺疊機的正式規範。在正式規範出來之前，收到特別需求時，請營運依下列方式提供視覺。

## 給營運：三個版型

| 版型 | 寬度 | 縮放方式 | 設計稿寬 | 內文最小字級（設計稿上） |
|---|---|---|---|---|
| 手機 | 480px 以下 | VW 整體縮放 | 375px（2 倍稿 750px） | 14px |
| 摺疊展開／小平板 | 481px～768px | VW 整體縮放 | 720px（2 倍稿 1440px） | 18px |
| 寬版 | 769px 以上 | 不縮放，內容置中 | 1280px，內容區最寬 1200px | 16px |

- **設計稿寬是縮放的基準。** 畫面在這個寬度時和設計稿一模一樣，比較窄的畫面等比縮小，比較寬的等比放大。
- **縮放範圍要留意。**
  - 「手機」：實際寬度 349～480，畫面約是設計稿的 0.93～1.28 倍。
  - 「摺疊展開」：實際寬度大多是 626～756（0.87～1.05 倍）。最窄到 481 時只剩 0.67 倍，所以內文在設計稿上至少要 18px，縮到最小才不會低於 12px。
- **「寬版」不縮放，所以要撐得住比較窄的寬度。** 內容寬度要能從 834px（摺疊機內螢幕橫向）伸展到桌機，請不要只出 1920px 的稿。
- **主視覺不要設計成剛好一個畫面高。** 摺疊機橫向或分割視窗時，畫面高度只有 223～445px，主視覺會被切掉。重要的按鈕和文字不要放在主視覺底部。
- **橫向與分割視窗不另外出視覺。** 這些狀態沿用對應寬度的版型，只要能正常捲動閱讀就好。

## 給前端：實作方式

```css
/* 用範圍語法：螢幕寬度可能有小數（例如 480.4），
   寫成 max-width: 480px / min-width: 481px 會有一段落在兩邊都不符合 */
:root { --base: 375; --u: calc(100vw / var(--base)); }               /* 480 以下 */
@media (480px < width <= 768px) { :root { --base: 720; } }             /* 481～768 */
@media (width > 768px) { :root { --u: 1px; } }                         /* 769 以上：不縮放 */

/* 設計稿標 N px，就寫 calc(N * var(--u)) */
.title { font-size: calc(32 * var(--u)); }
.card  { padding: calc(24 * var(--u)); border-radius: calc(12 * var(--u)); }

/* 內文設下限，避免 481px 附近縮太小 */
body { font-size: max(12px, calc(16 * var(--u))); }

/* 769 以上：內容置中，欄寬用 % 或 fr */
@media (width > 768px) {
  .container { max-width: 1200px; margin-inline: auto; padding-inline: 24px; }
}

/* 矮畫面：橫向、上下分割 */
@media (height <= 460px) {
  .hero { min-height: auto; }
}
```

- **用 `--u` 縮放的範圍**：字級、間距、圖示、圓角用 `--u` 縮放；容器寬度用 `%`、`fr`，不要用 vw。
- **高度單位**：用 `svh` 或 `dvh`，不要用 `vh`。摺疊機內螢幕的網址列會差 96px。
- **範圍語法的支援度**：`width <= 480px` 這種寫法需要 Chrome 104、Safari 16.4 以上。如果要支援更舊的瀏覽器，改寫成 `max-width: 480.98px` 與 `min-width: 481px`。

## 跟原本的版本比較

| 原本 | 調整後 | 原因 |
|---|---|---|
| 只寫寬度區間 | 每個區間都指定設計稿寬 | VW 縮放需要一個基準寬，否則營運和前端對不上 |
| 「小於 480px」與「481px～768px」 | 改成「480px 以下」與「481px～768px」 | 原本 480px 剛好落在兩段之間；前端另外要處理小數寬度 |
| 769px 以上沒有說明 | 不縮放、內容置中，並要在 834px 檢查 | 摺疊機內螢幕橫向（834～932）會落在這一段 |
| 沒提到字級 | 每一段都訂內文最小字級 | 481px 會縮到設計稿的 0.67 倍 |
| 沒提到高度 | 主視覺不要剛好一個畫面高；橫向與分割視窗不另外出稿 | 摺疊機橫向與分割視窗只有 223～445px 高 |
| 附錄只有 iPhone | 補上 Galaxy Z Fold8／Ultra，並列出每台裝置落在哪個版型 | 方便營運確認自己的稿會在哪些裝置上出現 |
