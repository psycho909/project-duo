# 摺疊機版面偵測

在實體摺疊機（Galaxy Z Fold8、iPhone Duo 等）上開啟，量出各種摺疊、方向、分割視窗狀態下的網頁尺寸，作為 HTML／CSS 斷點的依據。

## 使用流程

1. 用手機瀏覽器直接開啟頁面網址（不要嵌在其他網頁的 iframe 裡，否則量到的是框架尺寸）。
2. 第一屏顯示目前的網頁寬 × 高與螢幕數。
3. 依「已量測的狀態」裡的清單切換：外螢幕直／橫、內螢幕展開直／橫、分割視窗、浮動視窗、半摺、跨摺痕。每種狀態停留約 1 秒就會自動記錄，紀錄存在手機瀏覽器裡。
4. 「建議斷點」會依實測寬度產生 mobile-first 的 `@media` 斷點，按「複製 CSS」帶回專案使用；「複製紀錄表」可貼到試算表或回報給團隊。

## 版型分類

- **A. 窄版單視窗**：外螢幕、內螢幕分割視窗、浮動視窗
- **B. 寬版連續畫面**：內螢幕展開，網頁佔滿整片
- **C. 跨摺痕分區（左右）**：瀏覽器回報兩個 viewport segment
- **D. 半摺上下分區**：筆電／桌上模式

## 注意

- 摺痕分區（Viewport Segments）與摺疊姿態（Device Posture）只有 Chromium 系瀏覽器支援，iOS Safari 只能量到單一畫面的尺寸。
- Samsung Internet、Chrome 的網址列高度不同，同一狀態請兩種瀏覽器各量一次。
- 頁面被雙指縮放時不會自動記錄，請先縮回原大小。
