# 摺疊機版面偵測

在實體摺疊機（Galaxy Z Fold8、iPhone Duo 等）上開啟，量出各種摺疊、方向、分割視窗狀態下的網頁尺寸與螢幕數，作為 HTML／CSS 斷點與版面規格的依據。

**網址：https://project-duo.netlify.app/**（Netlify 連結此 repo，push 到 `main` 後自動部署）

## 使用流程

1. **量測**：用手機瀏覽器直接開啟網址。第一屏顯示目前的網頁寬 × 高與螢幕數。依「已量測的狀態」清單切換：外螢幕直／橫、內螢幕展開直／橫、分割視窗、浮動視窗、半摺、跨摺痕，每種停留約 1 秒自動記錄；點輸入框叫出鍵盤，記下打字時的可視高度。不知道怎麼切換時，展開「怎麼切換到這些狀態」。
2. **比較**：「畫板總覽」把所有狀態用同一比例並排，按「複製畫板尺寸」可直接在 Figma 建立對應畫框。
3. **決定斷點**：「建議斷點」把相差 40px 以內的寬度併成一組，斷點取相鄰兩組的中點；近方形的內螢幕另外給長寬比查詢，橫向矮螢幕給高度查詢。可輸出 CSS（px／em）、SCSS、Tailwind、JSON token。
4. **版面規格**：「這個寬度的版面規格」依 Material 3 級距給網格欄數、邊距、欄距、建議窗格數、16px 內文每行字數與摺痕避讓位置。
5. **對照公司規範**：「公司 RWD 臨時規範」顯示目前落在哪一級（≤ 480／481–768／≥ 769）、vw 倍率、設計畫板與圖片輸出尺寸，並列出已知裝置的落點。比對與調整建議見 [docs/rwd-temp-spec-review.md](docs/rwd-temp-spec-review.md)。
6. **回報**：「複製紀錄表」可貼到試算表，內含瀏覽器、裝置型號與頁面版本。

## 版型分類

- **A. 窄版單視窗**：外螢幕、內螢幕分割視窗、浮動視窗
- **B. 寬版連續畫面**：內螢幕展開，網頁佔滿整片
- **C. 跨摺痕分區（左右）**：瀏覽器回報兩個 viewport segment
- **D. 半摺上下分區**：筆電／桌上模式

## 注意

- 摺痕分區（Viewport Segments）與摺疊姿態（Device Posture）只有 Chromium 系瀏覽器支援，iOS Safari 只能量到單一畫面的尺寸。
- Samsung Internet 與 Chrome 的網址列高度不同，紀錄也分開保存，同一狀態請兩種瀏覽器各量一次。
- 頁面被雙指縮放時不會自動記錄，請先縮回原大小。
- 系統字級被調整時，1rem 不等於 16px；用 em 斷點會跟著字級縮放。
