螢幕數

–

已量測的狀態

在手機上每換一種狀態（摺起、展開、旋轉、分割視窗），停留約 1 秒就會自動記錄。紀錄存在這台手機的瀏覽器裡，重新整理也不會消失。

    建議斷點

    依已量測的寬度排序，相差 40px 以內的寬度併成一組，斷點取相鄰兩組的中點，讓每種狀態都離斷點有餘裕，不會因為瀏覽器工具列或捲軸的幾 px 差異跳版。

    目前版型

    – 偵測中

    這個頁面嵌在其他網頁的框架裡（例如 Claude 的 Artifact 檢視器），量到的是框架尺寸，且瀏覽器通常不會把摺痕分區回報給框架。要量實機的完整數值，請直接開啟頁面網址。

    1. A. 窄版單視窗

      外螢幕、內螢幕分割視窗、浮動視窗。單欄內容、底部導覽、點清單項目後換頁。

    2. B. 寬版連續畫面

      內螢幕展開且網頁佔滿整片。雙欄 list-detail，避免把按鈕或標題斷行放在 50% 寬的摺痕處。

    3. C. 跨摺痕分區（左右）

      瀏覽器回報兩個 viewport segment。兩欄各對齊一個分區，轉軸區不放文字或按鈕。

    4. D. 半摺，上下分區

      筆電／桌上模式。上半部放內容，下半部放操作。

    判斷邏輯

    • 螢幕數：window.viewport.segments 回報 2 個以上分區，就是跨摺痕（C 或 D）。目前只有支援 Viewport Segments API 的 Chromium 瀏覽器會回報，iOS Safari 不支援。
    • 內螢幕或外螢幕：長邊除以短邊小於 1.5 且短邊至少 600px 是內螢幕；短邊小於 520px 是外螢幕或一般手機。
    • 連續畫面或多工視窗：視窗寬度不到螢幕的 90%，或高度不到 70%，當作單螢幕處理。
    • 版型：最後由視窗寬度決定，小於 600px 單欄，600px 以上雙欄。
    純 CSS 寫法 
    /* A：窄版單欄（預設） */
.app { display: grid; grid-template-columns: 1fr; }

/* B：寬版連續畫面 → 雙欄 */
@media (min-width: 600px) {
  .app { grid-template-columns: 2fr 3fr; }
}

/* C：左右兩個 segment → 依摺痕對齊 */
@media (horizontal-viewport-segments: 2) {
  .app {
    grid-template-columns:
      env(viewport-segment-width 0 0)
      calc(env(viewport-segment-left 1 0) - env(viewport-segment-right 0 0))
      env(viewport-segment-width 1 0);
  }
}

/* D：上下兩個 segment（半摺／筆電模式） */
@media (vertical-viewport-segments: 2) {
  .app {
    grid-template-rows:
      env(viewport-segment-height 0 0)
      calc(env(viewport-segment-top 0 1) - env(viewport-segment-bottom 0 0))
      env(viewport-segment-height 0 1);
  }
}

/* 摺疊姿態（Device Posture API） */
@media (device-posture: folded) { /* 書本／筆電姿勢 */ }
