已量測的狀態

每換一種狀態（摺起、展開、旋轉、分割視窗），停留約 1 秒就會自動記錄。紀錄存在這個瀏覽器裡，重新整理也不會消失；Chrome 與 Samsung Internet 的紀錄分開保存。

    怎麼切換到這些狀態
    • 外螢幕直／橫：摺起手機，用外螢幕開啟本頁。要量橫向，先在快速設定開啟「自動旋轉」。
    • 內螢幕展開直／橫：打開手機。若瀏覽器沒有接續到內螢幕，直接在內螢幕重新開啟本頁。
    • 內螢幕分割視窗：從側邊工作列把另一個 App 拖到畫面一側，左右各量一次，也可以拖動中間的分隔線量不同比例。
    • 浮動／彈出視窗：在最近使用的 App 畫面，點瀏覽器圖示選「以彈出式視窗開啟」。
    • 半摺上下（Flex）：內螢幕展開後，把手機摺到約 90 度，像筆電一樣橫放。
    • 跨摺痕左右：半摺後直放，像一本打開的書。
    • 半摺時若螢幕數仍顯示 1，代表這個瀏覽器不支援 Viewport Segments，畫面會被當成一整片處理；iOS Safari 一律如此。

    畫板總覽

    所有狀態用同一比例並排，高度取網址列收起時的最大值。尺寸可直接在 Figma 建立對應的畫框。

    建議斷點

    相差 40px 以內的寬度併成一組，斷點取相鄰兩組的中點，讓每種狀態都離斷點有餘裕，不會因為工具列或捲軸的幾 px 差異跳版。

    目前版型

    – 偵測中

    這個頁面嵌在其他網頁的框架裡，量到的是框架尺寸，且瀏覽器通常不會把摺痕分區回報給框架。要量實機的完整數值，請直接開啟頁面網址。

    1. A. 窄版單視窗

      外螢幕、內螢幕分割視窗、浮動視窗。單欄內容、底部導覽、點清單項目後換頁。

    2. B. 寬版連續畫面

      內螢幕展開且網頁佔滿整片。雙欄 list-detail，避免把按鈕或標題斷行放在畫面中線的摺痕處。

    3. C. 跨摺痕分區（左右）

      瀏覽器回報兩個 viewport segment。兩欄各對齊一個分區，轉軸區不放文字或按鈕。

    4. D. 半摺，上下分區

      筆電／桌上模式。上半部放內容，下半部放操作。

    公司 RWD 臨時規範

    ≤ 480、481–768 用 vw 等比縮放，769 以上用 px。畫板寬、倍率上限與矮畫面規則是依實測補上的建議值，見 docs/rwd-temp-spec-review.md。

    已知裝置落在哪一級

    這個寬度的版面規格

    依 Material 3 視窗級距給的網格建議，以及用 16px 內文估算的每行字數。

    完整偵測數據

    在實機上複製後貼回來，用來校正判斷門檻。

    判斷邏輯

    • 螢幕數：window.viewport.segments 回報 2 個以上分區，就是跨摺痕（C 或 D）。目前只有支援 Viewport Segments API 的 Chromium 瀏覽器會回報，iOS Safari 不支援。
    • 內螢幕或外螢幕：長邊除以短邊小於 1.5 且短邊至少 600px 是內螢幕；短邊小於 520px 是外螢幕或一般手機。
    • 連續畫面或多工視窗：視窗寬度不到螢幕的 80%，或高度不到 65%，當作單螢幕處理。
    • 版型：最後由視窗寬度決定，小於 600px 單欄，600px 以上雙欄。
    純 CSS 寫法 
    /* A：窄版單欄（預設） */
.app { display: grid; grid-template-columns: 1fr; }

/* B：寬版連續畫面 → 雙欄 */
@media (min-width: 600px) {
  .app { grid-template-columns: 2fr 3fr; }
}

/* C：左右兩個 segment → 依摺痕對齊 */
@media (horizontal-viewport-segments: 2) {
  .app {
    grid-template-columns:
      env(viewport-segment-width 0 0)
      calc(env(viewport-segment-left 1 0) - env(viewport-segment-right 0 0))
      env(viewport-segment-width 1 0);
  }
}

/* D：上下兩個 segment（半摺／筆電模式） */
@media (vertical-viewport-segments: 2) {
  .app {
    grid-template-rows:
      env(viewport-segment-height 0 0)
      calc(env(viewport-segment-top 0 1) - env(viewport-segment-bottom 0 0))
      env(viewport-segment-height 0 1);
  }
}

/* 摺疊姿態（Device Posture API） */
@media (device-posture: folded) { /* 書本／筆電姿勢 */ }
